About Fraud Graph Explorer

A Django-based proof of concept designed to detect fraud in bank loan applications through link analysis.

This application allows users to generate synthetic, formally valid loan application sheets (PDF), ingest them, extract identifiers (VAT numbers, Tax Codes, names), and visualize the connections between different applications using an interactive graph.
